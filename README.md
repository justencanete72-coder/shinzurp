# 🌆 SHINZU WORLD RP 🎮

Isang **Fully Playable 3D Mobile Life Simulation Game** na inspired by open-world roleplay games, na binuo gamit ang **Three.js** at **WebGL**. 

Dinisenyo ito para sa mga Android phones at fully playable sa browser (PWA) nang walang kailangang i-download na APK.

## ✨ Current Features (Phase 3)
- **3D Open World:** Malayang paglalakad at pag-ikot ng camera sa isang 3D environment.
- **Smooth Mobile Controls:** Virtual joystick para sa paggalaw at touch-drag para sa camera.
- **Interactive Objects:** 
  - 🚪 **Pinto:** Pwedeng buksan at isara.
  - 🛏️ **Kama:** Pwedeng higaan (may animation ng pagtulog).
  - 🛋️ **Sofa:** Pwedeng upuan.
- **Graphics Settings:** Pwedeng i-adjust ang quality (Low, Medium, High) at patayin ang shadows para sa mas smooth na gameplay sa low-end phones.
- **Real-time FPS Monitor:** Makikita ang live frame rate ng phone mo.
- **PWA Support:** Pwedeng i-install bilang app sa Home Screen ng Android.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **3D Engine:** [Three.js](https://threejs.org/)
- **Deployment:** [Vercel](https://vercel.com/)
- **3D Models:** GLTF format (optimized for web)

---

## 📱 Paano Laruin (Mobile)
1. Buksan ang live link sa **Google Chrome (Android)**.
2. Pindutin ang **3 dots** sa kanang taas at piliin ang **"Install App"** o **"Add to Home Screen"**.
3. Buksan ang app at hintayin mag-load ang 3D world.
4. **Controls:**
   - **Kaliwang Bahagi:** Joystick para maglakad/tumakbo.
   - **Kanang Bahagi:** I-drag para iikot ang camera.
   - **Interact Button:** Lalabas kapag malapit ka sa Pinto, Kama, o Sofa.
